# LookAway

LookAway is a macOS menu bar app for timed screen breaks. It keeps a lightweight work/break rhythm running in the background, warns you before a break starts, and shows a break overlay when it is time to step away for a moment.

## What It Does

LookAway helps reduce eye strain and nonstop screen time by:

- running a recurring break schedule from the menu bar
- showing the next break time and current state at a glance
- giving a pre-break warning before the overlay appears
- delaying breaks during meetings, focus blocks, or outside work hours
- letting you snooze, skip, pause, or trigger a break manually

## Core Features

### Menu Bar Workflow

- Menu bar presence with quick status
- Shows current state such as working, paused, break soon, meeting, or focus block
- Quick actions for:
  - `Start Break`
  - `Snooze 5m`
  - `Snooze 10m`
  - `Skip Once`
  - `Pause reminders`

### Break Scheduling

- Built-in rhythms such as:
  - `20-20-20`
  - `Pomodoro`
  - `Gentle`
  - `Deep Work`
- Custom interval and break duration controls
- Multiple break styles such as coffee reset, breathing, stretch, blink, and hydration

### Pre-Break Alerts

- Optional 30-second pre-alert
- Two alert modes:
  - `Countdown beside pointer`
  - `Center-screen banner`
- Built-in test action to preview the pre-break cue and break flow without waiting for a full work cycle

### Focus and Schedule Controls

- Restrict reminders to work hours and selected weekdays
- Focus blocks for heads-down time
- Calendar-aware break delay
- Option to only block for accepted calendar events

### System-Aware Behavior

- Launch at login
- Pause on lock or sleep
- Device-aware timing adjustments
- Reduced intensity on battery or low power mode
- Menu bar display modes:
  - icon only
  - icon + minutes
  - icon + status

## Preferences

The app is organized into four settings areas:

- `Schedule`
  - quick setup presets
  - work hours
- `Breaks`
  - break timing
  - break style
- `Focus`
  - calendar integration
  - focus blocks
  - recovery behavior
- `Advanced`
  - overlay feel
  - menu bar behavior
  - device awareness
  - testing
  - diagnostics
  - privacy reset tools
